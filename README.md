# Статическое портфолио разработчика

Статический сайт-портфолио для GitHub Pages без React, Vite и сборки. Контент вынесен в JSON-файлы, поэтому тексты, проекты, навыки, опыт и контакты можно менять без правки HTML.

## Структура

```text
index.html
assets/
  css/
    style.css
  js/
    main.js
data/
  profile.json
  projects.json
  skills.json
  experience.json
README.md
```

## Как редактировать контент

Основные данные лежат в папке `data`.

`data/profile.json`:

- имя, полное имя и роль;
- пункты навигации;
- hero-блок;
- карточка текущего фокуса;
- текст "Обо мне";
- факты;
- контакты;
- текст футера.

`data/projects.json`:

- список проектов;
- тип проекта;
- описание;
- стек;
- ключевые пункты для карточки;
- поле `layout`, которое управляет визуальным весом карточки:
  - `primary` для главного проекта;
  - `secondary` для второго крупного проекта;
  - `compact` для небольшого второстепенного проекта.

`data/skills.json`:

- группы навыков;
- список тегов внутри каждой группы.

`data/experience.json`:

- компания;
- роль;
- период;
- описание;
- обязанности;
- стек.

JSON-файлы должны оставаться валидными: без комментариев, лишних запятых и одинарных кавычек.

## Как заменить контакты

Откройте `data/profile.json` и замените значения в блоке `contacts.links`.

Пример:

```json
{
  "label": "Telegram",
  "href": "https://t.me/your_username"
}
```

Для email используйте формат:

```json
{
  "label": "Email",
  "href": "mailto:your.email@example.com"
}
```

## Как запустить локально

Так как сайт загружает данные через `fetch()` из JSON-файлов, надежнее запускать его через локальный сервер.

```bash
python -m http.server 8000
```

После запуска откройте:

```text
http://localhost:8000
```

Открытие `index.html` двойным кликом может работать не во всех браузерах из-за ограничений доступа к локальным JSON-файлам.

## Как задеплоить на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите в него все файлы проекта.
3. Откройте настройки репозитория.
4. Перейдите в `Pages`.
5. В `Build and deployment` выберите `Deploy from a branch`.
6. Выберите ветку `main` или `master`.
7. В качестве папки выберите `/root`.
8. Сохраните настройки.

Через несколько минут сайт будет доступен по адресу GitHub Pages.

## Что можно менять в дизайне

Основные стили находятся в `assets/css/style.css`.

Чаще всего достаточно изменить переменные в начале файла:

```css
:root {
  --bg: #111211;
  --text: #f4f2ed;
  --accent: #b5ea67;
}
```

JavaScript находится в `assets/js/main.js`. Он отвечает только за загрузку JSON, сборку секций и мобильное меню.
